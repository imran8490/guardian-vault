Recent vault moves

Verdicts that crossed a threshold and called for a de-risk or a re-risk.

    The AI service publishes a score to the RiskOracle on Base Sepolia. The Reactive contract on Lasna watches that event and decides, with hysteresis, a cooldown and replay protection, whether the vault should move.

    The vault does not trust the callback alone. It reads the oracle itself and refuses the move if the score does not support it.

    Whether the vault actually acted is on-chain: see "Last verdict the vault acted on" in the Vault readout above.

      The loop

      No keeper bot and no admin button sits between the verdict and the vault. Each step runs on the chain shown above it.

      If the AI does not answer

      A second path in the v3 contracts (GuardianReactiveV3, GuardianVaultV3). It never replaces the AI: the AI gets the first 30 seconds. The Watchdog line at the top of this page shows whether the contracts read here are v3.

      1. AReactive LasnaWatches the poolReactive also subscribes to the pool's Swap events and keeps the last price.
      2. BReactive LasnaStarts a timerPrice at or below the stop level (40% under entry) starts a 30 s grace timer.
      3. CReactive LasnaTripsIf the vault is still risk-on when the timer ends, it asks the vault to de-risk.
      4. DBase SepoliaVault checks itselfIt re-reads the pool price and refuses unless it is really below its own stop level.
